# 九重キャンプ 道具マップ

66品目を7カテゴリー、または5つの収納先から辿るホームページです（車両本体は別枠）。写真は64品目、写真未登録は2品目です。マップ、カテゴリー別一覧、全品目検索、数量・備考付きの写真詳細を利用できます。

## 公開方法

このフォルダの**中身**をGitHubリポジトリのルートへ配置し、Settings → Pages → Sourceで「Deploy from a branch」を選び、`main` / `/(root)` を保存してください。ビルド作業・npm・APIキーは不要です。

フォルダ構成は次の通りです。ZIPファイルそのものではなく、解凍した中身をアップロードします。

```text
index.html
style.css
app.js
data.js
favicon.svg
.nojekyll
.gitignore
README.md
assets/
  gear-00.jpg ... gear-56.jpg
  gear-57.webp
```

GitHub Pagesの設定方法: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## ローカルでの確認

このフォルダ内で次を実行し、表示されたローカルURLをブラウザで開きます。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

## 操作

- 「カテゴリー別」「収納場所別」を切り替え、マップから道具を辿れます。
- 詳細で収納場所・有無・積込確認・数量・備考を確認できます。
- 各道具の詳細で、有無確認と積込確認を選択できます。選択はlocalStorageに保存され、同じブラウザーで開き直すと復元します。
- 初期値はExcelからの転記です。選択の変更はほかの端末・仲間の画面やExcelへ自動同期されません。
- 「一覧」はカテゴリーごとに折りたためます。
- 検索はすべてのカテゴリーが対象です。
- 詳細画面の左右ボタンで、同じカテゴリーの道具を辿れます。
- スマートフォン幅では、枝を縦に並べて表示します。
- ブラウザの戻る操作と、URLでのカテゴリー・物品指定に対応します。

## データ

`data.js` に名称・数量・カテゴリー・収納先・有無・積込状況・備考・写真パスを保存しています。2026年11月3日に受領したExcelの66品目を反映しています。写真のないゴム手袋・三脚は「写真未登録」と表示します。Notionとの自動同期はありません。

写真は `assets/` に格納した900px以下の軽量JPEG/WebPです。透明な写真は透明部分を保って保存します。画像の位置情報などのExifを除いています。外部ライブラリ、CDN、ログイン、外部APIへの通信は不要です。

親フォルダの元写真、バックアップ、作業用設定は、この公開用フォルダに含めていません。
