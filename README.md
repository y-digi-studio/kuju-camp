# 九重キャンプ情報まとめ

103品目・7カテゴリー・7収納場所の一覧、キャンプ場情報、行程・マップ、料理をまとめたアプリです。写真は72品目に登録されています。

## 共有保存の使い方

1. 共有用リンクからアプリを開きます。共有画面と保存先は同じサイト内です。以前のGitHub Pagesの共有リンクも、編集用の情報を引き継いで共有画面へ移動します。
2. 「持ち物を追加」で名称・数量・カテゴリー・収納場所・確認状況・写真・備考を入力し、「共有して保存」を押します。
3. 道具の詳細の「編集」「削除」から変更できます。削除した品物は「ゴミ箱」で復元できます。
4. 詳細の有無確認・積込確認も共有先に保存されます。画面を開いている仲間には約10秒ごとに変更が反映されます。「更新」ですぐ読み直せます。
5. 「共有リンク」から仲間に送るリンクをコピーできます。リンクを知っている人は一覧の閲覧・追加・編集・削除ができます。公開投稿に貼らず、利用する仲間へ送ってください。

同じ品物への更新が重なると、後の更新を止めて最新内容の確認を促します。通信できない間は保存できません。保存成功の表示を確認してください。共有先への接続がない場合は、公開時の一覧を閲覧できます。

初回の通信に失敗しても、受け取ったリンクを保持します。「更新」で再試行できます。端末内の保存が制限されていても、その共有リンクを開いている間は利用できます。アドレス欄にも共有情報を維持するので、共有用リンクとして送り直せます。

従来この端末だけに保存していた有無・積込確認は、「共有リンク」内の「この端末の確認状況を共有に反映」で、確認してから移せます。共有先の既存状況が置き換わるため、内容を確認してください。

## 保存先とデータ

- 公開入口：GitHub Pages。共有用の操作画面：共有保存サービス内の `/camp/index.html`。`data.js` は初期一覧で、動的な変更の保存先ではありません。
- 共有一覧：SitesのCloudflare D1。写真の追加先：Cloudflare R2。公開API接続先は `shared-config.js` に記載しています。
- 共有用リンクの編集キーは公開ソースに含めません。D1のハッシュで照合し、管理者用のリンク確認にはSitesの秘密環境変数を使用します。利用者のブラウザーにも接続情報を保存します。
- 自宅住所は端末内の `kuju-camp-home-v1` にのみ保存されます。共有データには含めません。
- Excel・Notionとは自動同期しません。「一覧のバックアップを保存」で現在の共有データをJSONとして保存できます。
- 共有データはアプリの再公開でリセットされません。初期登録は一度だけです。

## 公開・保守

このフォルダの中身がGitHub Pagesの公開ファイルです。共有保存サーバーのソースは親フォルダの `shared-service` にあります。共有保存を利用するには通信が必要です。

`assets/` の既存写真はJPEG/WebP、料理写真はPNGです。追加写真はブラウザーで最大1200pxのJPEGに変換し、位置情報などのExifを含めずに保存します。
